# Portfolio edition notes

This public repository has a new showcase identity and clean initial history. It is derived from an existing codebase owned by the portfolio author; it is not represented as a newly shipped client application.

Screenshots show actual local application builds with illustrative data. Runtime secrets, original signing material and production accounts are not required for the preview. Public source review is not a security certification of the original deployed service.

The original private project is maintained separately. Changes to this edition do not rotate credentials in the original service or remove material from that private repository's history.
